# AI Studio 参考提示词模板

将本目录中的参考文档与截图上传到 Google AI Studio 后，可直接使用（或微调）下面这段提示词，让 AI Studio 完整复刻其视觉质感、交互骨架与等距图解体验，并替换为你自己的新主题。

---

## 复制即用 Prompt（将 `[你的新主题]` 替换为具体内容）

```markdown
我上传了一份参考网站的完整设计资料与截图包，原站是 `Algo Lab (byte-sized-algorithms.vercel.app)`。我希望你**完整借鉴它的视觉风格、布局结构、交互体验与 2.5D 等距 SVG 图解风格**，为我构建一个全新的互动学习 Web 应用，主题是：

> **新主题：[在这里填写你的新主题，例如：Transformer 与大语言模型核心原理 / Git 内部机制与工作流 / 现代 HTTP 与分布式系统入门]**

### 一、必读参考资料（已随对话附带）
1. **视觉截图**（`screenshots/01` ~ `05`）：请严格对齐截图中的「暖调纸质实验室（Warm Paper Lab）」质感、排版呼吸感、珊瑚橙高光、斜线阴影等距方块，以及深色模式与移动端吸顶布局。
2. **`DESIGN_SYSTEM.md` & `design-tokens.css`**：请直接复用其中的 Light/Dark CSS 变量（如 `--page: #f7f4ee`、`--coral: #e2705a`、`--iso-blush: #fbe2d8` 等）、`body:after` 纸张噪点纹理、阴影、圆角和三栏响应式断点。
3. **`INTERACTION_AND_UX.md`**：请复用其单屏工作台架构（顶栏 + 左侧可折叠课程树 + 中央等距舞台与横向步骤时间轴 + 右侧讲解/代码或公式联动高亮/实时指标卡），以及 `ArrowLeft`/`ArrowRight` 切步、`Cmd/Ctrl+K` 全局搜索、主题持久化、Hash 路由 `#/<lesson>/<step>` 和完成进度记录。
4. **`SCENE_ENGINE_AND_SCHEMA.md` & `sample-lessons.json`**：请采用「声明式课程 Schema + 步骤状态驱动的 25° 等距 SVG 场景引擎」。每个步骤切换时，图解元素应有平滑的位置过渡、入场落体/离场动画以及高亮反馈。

### 二、针对新主题的定制要求
1. **课程规划**：请先为「[你的新主题]」设计一套循序渐进的微课目录（建议 4~6 章，共 12~20 课；优先完整实现前 6~8 课的可交互完整内容，其余课节可先占位或同步实现），每课 5~7 个步骤。
2. **图解隐喻设计**：不要生搬硬套算法里的栈和数组，请为新主题设计贴合的 2.5D 等距 SVG 视觉隐喻（保持 25° 投影、顶面/左面/右侧斜线阴影面、圆角描边、悬浮 Tag 标注和移动高亮效果）。
3. **右侧联动卡片**：
   - **讲解卡**：每步控制在 2~3 句通俗短文，善用 `note` 提示框点出直觉或常见误区。
   - **代码/公式/报文卡**（对应原站 Pseudocode）：改为最适合本主题的内容（如命令行、协议报文、公式推导或关键配置），并随步骤高亮对应行号（`lines`）。
   - **实时指标卡**（对应原站 Facts）：展示随当前步骤动态变化的数值、标签 chips 或进度条。
4. **语言**：界面文字与课程内容全部使用**简体中文**（专有名词可保留英文对照）。

### 三、技术栈与交付要求
- 使用纯前端 React + TypeScript（或你擅长的原生 ES Modules / Vite 单页应用），**零外部重量级 3D 库**，等距图形全部用干净的 SVG 矢量组件实现，确保明暗主题切换时图解颜色实时同步。
- 请先输出你的**架构与课程大纲设计**，然后直接给出完整可运行的代码实现。
```

## 进阶用法建议（在 AI Studio 中分两步效果更好）

1. **第一步（搭骨架 + 跑通 2 节示范课）**：先让 AI Studio 基于上传的 `DESIGN_SYSTEM.md`、`design-tokens.css` 和 `SCENE_ENGINE_AND_SCHEMA.md` 搭建好「三栏布局 + 主题/搜索/时间轴框架 + 等距 SVG 基础图元（方块、底座、箭头、悬浮 Tag）」，并完整做出前 2 节课验证视觉效果。
2. **第二步（批量扩充课程数据）**：确认样式与动画满意后，把 `sample-lessons.json` 作为 Few-Shot 示例，让它继续批量生成后续章节的 `steps` 状态数据与新场景组件。
